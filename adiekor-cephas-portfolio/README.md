# Adiekor Cephas — Professional Portfolio

A responsive, single-page portfolio built with semantic HTML, CSS and vanilla JavaScript.

## Contents
- `index.html` — portfolio content and page structure
- `styles.css` — responsive visual design and accessibility styles
- `contact.css` — responsive direct-contact layout
- `script.js` — mobile navigation behaviour
- `assets/Adiekor-Cephas-CV.pdf` — supplied CV (if included)

## Run locally
1. Extract the ZIP file.
2. Open the `adiekor-cephas-portfolio` folder.
3. Double-click `index.html`, or run a local server:
   - With Python: `python -m http.server 8000`
   - Open `http://localhost:8000`

No build step, package manager or framework is required. Google Fonts are loaded online; system fallbacks are provided.

## Contact options
The portfolio provides direct email, phone and LinkedIn links with no message form or server-side data collection.

## Deploy
Upload the contents of this folder (not the ZIP itself) to any static web host, such as GitHub Pages, Netlify, Cloudflare Pages or a conventional web host. Ensure `index.html` is at the published site root and keep the `assets` folder alongside it.

### GitHub Pages (overview)
1. Create a GitHub repository for the portfolio.
2. Upload `index.html`, `styles.css`, `script.js` and `assets/`.
3. In repository Settings → Pages, select deployment from the `main` branch and root folder.
4. Save and wait for GitHub Pages to publish the site.

## Before publishing
- Confirm the CV PDF in `assets/` is present and current.
- Review the email address, phone number and LinkedIn URL.
- Add a professional headshot if desired; the current design uses an initials monogram rather than an unverified photo.
- Add GitHub repository/live-demo links only for projects that are publicly available.
- Test the site on mobile, tablet and desktop.
- If you use a custom domain, update canonical/social metadata as appropriate.

## Content integrity notes
Employment dates, titles, education, certification, listed tools and contact information were taken from the supplied CV. The project cards describe practical work documented in the CV; they are not presented as public software products. No unverified achievements, proficiency scores, project URLs or profile photograph have been added.
